Our system is called a pipeline because information flows through a sequence of processing stages. Each agent performs a different responsibility.
It is called multi-agent because we have four specialized LLM-powered components, each configured with its own role and instructions. These agents use the same underlying Groq-hosted model configuration; we are not training four separate LLMs.

3. Understanding the four types of Java files
Before explaining individual files, understand these four categories.

Controller classes
Receive HTTP requests and return responses. Example: WriterTestController.




Service classes
Contain application logic and coordinate operations. Example: PipelineOrchestrator.




Agent classes
Prepare prompts, call the LLM, and convert responses into structured results. Example: ResearcherAgent.




Model classes / records
Define the structure of data exchanged between classes. Example: ResearchResult.



This distinction is fundamental to understanding the whole application.
